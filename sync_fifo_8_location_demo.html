Key study points

Important: a FIFO read makes an entry logically invalid by advancing the read pointer and reducing the occupancy count. It does not have to clear the physical memory bits.
  • Write accepted: when write is requested and the FIFO is not full, store the input at the write pointer and advance it.
  • Read accepted: when read is requested and the FIFO is not empty, copy the oldest byte to data_out and advance the read pointer.
  • Empty: count == 0. Old memory bits may still be visible.
  • Full: count == 8. A write-only request is rejected.
  • Wraparound: after address 7, a pointer returns to address 0.
  • This is a behavioral teaching model, not a cycle-accurate simulator of a specific HDL implementation.
