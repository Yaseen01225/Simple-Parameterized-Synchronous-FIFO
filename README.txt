# 8-Location Synchronous FIFO — Study Demo

## Run it
Open `sync_fifo_8_location_demo.html` in a modern desktop or mobile browser. It works offline and requires no installation.

## Features
- Eight 8-bit memory locations
- Manual hexadecimal writes and FIFO reads
- Full/empty and occupancy indicators
- Read/write pointers and wraparound
- Memory visualization showing that reads do not erase stored bits
- Guided write/read sequence and operation log

## Important
This is an interactive behavioral teaching model, not an HDL simulator and not a cycle-accurate execution of a particular Verilog module. It demonstrates conventional FIFO semantics.
